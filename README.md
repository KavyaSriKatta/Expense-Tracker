Expense Tracker Web Application
--------------------------------

A simple, responsive web application for tracking daily income and expenses, monitoring spending, and managing personal finances efficiently.

Features :
---------

- Add and delete income and expense transactions
- Track total income, expenses, and balance
- Categorize and manage transactions
- Store transaction data using browser Local Storage
- Responsive and user-friendly interface

Technologies Used :
------------------

- HTML5 – Application structure
- CSS3 – Styling and responsive design
- JavaScript – Functionality and transaction management
- Local Storage – Persistent browser-based data storage

How to Run :
-----------

1. Clone or download this repository.
2. Open the project folder.
3. Open "HTML/index.html" in your web browser.
4. Start managing your income and expenses.

Project Objective :
-----------------

To develop a lightweight, user-friendly financial tracking application using core web technologies.
